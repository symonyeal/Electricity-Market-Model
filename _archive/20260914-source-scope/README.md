# Source scope removed from the active bibliography

On 2026-09-14, a table of Canadian public datasets was removed from
`docs/SOURCES.md`. None of those datasets was used by the pit model or its
planned model path, so keeping the scouting list in the active bibliography made
the repository's evidence harder to follow.

The original table remains recoverable from Git commit `3a74f39`. It is not
copied here because that would create the redundant copy the cleanup was meant
to remove.
